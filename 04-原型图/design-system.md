# 芽芽母婴会员营销系统 · 设计系统

> 项目编号 064　｜　方向：柔和母婴风格，藕粉主色，前台卡片圆角大、图片多，后台同主色清爽表格布局
> 视觉规范以需求文档第 10 节为准，本文件把文档里的色值、间距、字阶落成可复用的 token。

## 1. 色彩

| 用途 | 色值 | CSS 变量 | 使用场景 |
|---|---|---|---|
| 主色 | `#C86B85` | `--primary` | 顶部栏品牌块、主按钮、当前菜单、关键数字 |
| 辅助色 | `#E3A0B4` | `--primary-2` | 次级按钮、筛选选中态、图表第二系列 |
| 强调色 | `#7FB3A6` | `--accent` | 重点提示、待办数量、图表对比系列 |
| 页面背景 | `#F5F6F7` | `--bg` | 内容区底色，表格与表单用白色容器 |
| 卡片 | `#FFFFFF` | `--card` | 数据容器 |
| 正文 | `#1F2933` | `--ink` | 标题与正文 |
| 次要文字 | `#5B6770` | `--muted` | 说明、表头、时间 |
| 成功 | `#2B7955` | `--ok` | 已完成、已通过、正常 |
| 危险 | `#B02A37` | `--danger` | 驳回、超时、删除、售罄 |
| 分割线 | `#E7E4E6` | `--line` | 卡片边框、表格横线 |
| 浅色底 | `#FBF3F5` | `--soft` | 选中行、当前菜单浅底、提示块 |

派生规则：图表系列色从主色、辅助色、强调色与中性灰 `#D9DEE1` 派生；同一含义跨页面必须同色。
状态严禁只靠颜色表达，必须同时出现中文标签（如「已售罄」「高风险」）。

## 2. 字体与字阶

字族：`"PingFang SC", "Microsoft YaHei", system-ui, sans-serif`；数字统一 `font-variant-numeric: tabular-nums`。

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 20 / 28 | 700 | 内容区 h1 |
| 区块标题 | 14 / 22 | 600 | 卡片 h3 |
| 正文 | 14 / 22 | 400 | 表格、表单、说明 |
| 辅助 | 12.5 / 20 | 400 | 筛选标签、表头 |
| 微型 | 11.5 / 18 | 400 | 提示、图注 |
| 关键数字 | 24 / 32 | 700 | KPI 数值，字距 -0.5px |
| 金额强调 | 26 / 32 | 700 | 结算页实付 |

## 3. 圆角、阴影、间距

- 圆角：卡片与抽屉 `14px`，按钮与输入框 `9px`，标签 `6px`，前台商品卡 `16px`，胶囊 `999px`。
- 阴影：`0 1px 2px rgba(31,41,51,.04), 0 8px 24px rgba(31,41,51,.05)`；主按钮另加 `0 6px 14px rgba(200,107,133,.22)`。
- 间距阶梯：4 / 8 / 12 / 16 / 20 / 24 / 32。内容区外边距 24px，卡片内边距 18px，栅格间距 16px。
- 布局：侧边栏 220px（折叠 64px）、顶部栏 56px、内容区自适应；筛选项间距 12px。

| 组件 | 尺寸 | 规范 |

## 5. 图表

- 折线：近 30 天会员新增与复购，双系列，主色 + 强调色，平滑曲线，无面积填充。
- 环形：会员等级分布与流失风险分布，中心显示总数，图例带人数与占比。
- 柱状：各品类销售额，主色渐变柱。
- 漏斗：券领取到核销，四级宽度递减，每级显示数量。
- 直方：宝宝月龄段购买分布，横轴月龄段，纵轴订单数。
- 规则：默认近 30 天，可切本月/本季/本年/自定义；点击图元跳转到带同条件的列表。

## 6. 两套骨架

- 后台（店长、导购、运营、营销专员、管理员）：220px 侧边栏 + 56px 顶栏 + 内容区，侧边栏按「概览 / 会员 / 商品 / 营销 / 订单 / 系统」分组。
- 门户（会员家长）：64px 顶部导航 + 1180px 居中内容 + 商品卡栅格，顶部固定「宝宝月龄切换条」。
- 同系统多角色区分：后台顶栏角色标签区分身份（店长/运营/营销/导购/管理员），门户用藕粉品牌头部与卡片化内容。
